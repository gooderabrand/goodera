# Commit Message Guidelines

| Type        | Format                                            | Example                                            |
| ----------- | ------------------------------------------------- | -------------------------------------------------- |
| `feat:`     | New section/component/functionality               | `feat: add reviews section with dynamic metafield` |
| `fix:`      | Bug fixes                                         | `fix: resolve broken variant display logic`        |
| `style:`    | Design-only changes                               | `style: update spacing and typography for hero`    |
| `chore:`    | Cleanup, setup, non-feature                       | `chore: configure Shopify theme settings`          |
| `refactor:` | Logic or structural change without feature change | `refactor: simplify product-card logic`            |
